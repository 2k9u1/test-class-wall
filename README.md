# 우리 반 담벼락

메모를 쓰면 올린 순서대로 붙는 담벼락입니다. 연수 실습의 공통 시작점입니다.

## 지금 되는 것

- 메모 쓰기 (내용 쓰고 엔터)
- 메모 지우기 (× 버튼)
- 올린 순서대로 담벼락에 붙기

## 아직 안 되는 것

- **저장.** 데이터는 `app.js` 안의 배열에만 있습니다. 새로고침하면 사라집니다.
- **로그인.** 지금은 누구든 남의 메모를 지울 수 있습니다.
- **AI 도우미.** `api/gemini.js`가 아직 비어 있습니다.

이 세 가지를 오후 백엔드 시간에 붙입니다.

## 실행 방법

`index.html`을 **더블클릭하면 화면이 비어 있습니다.** 다음 방법으로 여세요.

Antigravity(또는 VS Code)에서 `Live Server` 확장을 설치하고,
`index.html`에 마우스 오른쪽 버튼 → `Open with Live Server`.

`http://127.0.0.1:5500` 같은 주소로 열리면 성공입니다.

> 왜 더블클릭하면 안 되나요?
> `app.js`를 모듈 방식으로 불러오는데, 브라우저는 보안 때문에
> 주소가 `file://`로 시작하면 모듈을 막습니다.
> Firebase를 붙이려면 이 방식이어야 해서, 처음부터 이렇게 해 두었습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 뼈대와 스타일 |
| `app.js` | 메모 데이터, 읽기·쓰기·지우기, 화면 그리기 |
| `api/gemini.js` | Gemini를 부를 서버 코드가 들어올 자리 |

## 요금제

Firebase는 **무료 요금제(Spark)** 로 진행합니다.
서버가 필요한 일(Gemini 호출)은 Firebase Functions 대신 Vercel의 무료 함수를 씁니다.
Firebase Functions는 유료 요금제(Blaze)라야 쓸 수 있기 때문입니다.
