# 성장형 교사개발자 과정 보드

차시별 학습 내용을 카드로 붙이는 보드입니다. 연수 실습의 공통 시작점입니다.

## 지금 되는 것

- 컬럼(차시)별로 카드 보기
- 카드 추가 (내용 쓰고 엔터)
- 카드 삭제 (× 버튼)

## 아직 안 되는 것

- **저장.** 데이터는 `app.js` 안의 배열에만 있습니다. 새로고침하면 사라집니다.
- **로그인.** 지금은 누구든 남의 카드를 지울 수 있습니다.

이 두 가지를 오후 백엔드 시간에 붙입니다.

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 별도 설치가 필요 없습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 뼈대와 스타일 |
| `app.js` | 데이터, 카드 추가·삭제, 화면 그리기 |
