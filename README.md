# 우리 반 담벼락

메모를 쓰면 올린 순서대로 붙는 담벼락입니다. 연수 실습의 공통 시작점입니다.

## 지금 되는 것

- 메모 쓰기 (내용 쓰고 엔터)
- 메모 지우기 (× 버튼)
- 올린 순서대로 담벼락에 붙기

## 아직 안 되는 것

- **저장.** 데이터는 `app.js` 안의 배열에만 있습니다. 새로고침하면 사라집니다.
- **로그인.** 지금은 누구든 남의 메모를 지울 수 있습니다.

이 두 가지를 오후 백엔드 시간에 붙입니다.

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 별도 설치가 필요 없습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 뼈대와 스타일 |
| `app.js` | 메모 데이터, 쓰기·지우기, 화면 그리기 |
